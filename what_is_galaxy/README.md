# What is Galaxy?

An interactive slideshow introducing the Galaxy Project - a free, open-source platform for data-intensive biomedical research.

## View Online

**https://nekrut.github.io/infographics/what_is_galaxy/**

## Contents

14 slides covering:

1. **Galaxy Stats** - Key metrics (750K jobs/mo, 400K users, $2M compute)
2. **Get your data** - Upload from anywhere
3. **Run a tool** - 1,000s of analysis tools
4. **Run a workflow** - Community curated workflows
5. **Interpret & publish** - Jupyter, RStudio, AI tools
6. **Highly Scalable** - ACCESS-CI infrastructure
7. **Tool Ecosystem** - BioConda, BioContainers integration
8. **Training Hub** - GTN with 489 tutorials
9. **Applications** - Genomics, proteomics, and more
10. **Genome Assembly** - Vertebrate Genomes Project
11. **Global Instances** - usegalaxy.org, .eu, .org.au
12. **Galaxy Ecosystem** - IUC, IWC, Planemo, Pulsar, TPV
13. **Key Links** - Quick access to Galaxy resources
14. **QR Code** - Scan to visit gxy.io/what-is-galaxy
